## 🚀 Firebase Deployment (Quick Steps)

```powershell
# 1. Folder me jayein
cd d:\my-apps\tarunmankar.github.io\apps-hub

# 2. Login karein
firebase login

# 3. Project select karein
firebase use --add

# 4. Deploy karein
firebase deploy --only hosting
```

Custom domain connect karne ke liye Firebase Console me **Hosting -> Add custom domain** me apna domain (`tapapp.web.in` ya jo bhi domain choose karein) daalein aur DNS me A & TXT records set karein.
